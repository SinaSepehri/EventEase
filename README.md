# EventEase

A Blazor WebAssembly (.NET 10) app for browsing events, registering for them, and tracking attendance.
Built as the final project for the *Blazor for Front-End Development* course of the Microsoft Full-Stack Developer certificate.

| Folder | Contents |
|---|---|
| [`EventEase/`](EventEase) | The app: Event Card, routing, Registration Form, user sessions, Attendance Tracker |
| [`EventEase.Tests/`](EventEase.Tests) | 126 xUnit + bUnit tests |

See [EventEase/README.md](EventEase/README.md) for the full write-up: features, bugs fixed, performance measurements,
and how GitHub Copilot helped.

## Run

Requires the [.NET 10 SDK](https://dotnet.microsoft.com/download).

```bash
dotnet run --project EventEase
```

## Test

```bash
dotnet test
```
